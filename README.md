# Matplotlib Assessment

## About
This repository contains a Jupyter Notebook for practising data visualization using Python and Matplotlib.

## Technologies Used
- Python
- Matplotlib
- Jupyter Notebook

## Project File
- `MatSea.ipynb` — Notebook containing the assessment work.

## Learning Outcomes
- Understanding data visualization concepts.
- Practising plotting and chart creation with Matplotlib.
- Exploring how visualizations help interpret data.

## How to Run
1. Download or clone this repository.
2. Open `MatSea.ipynb` using Jupyter Notebook or JupyterLab.
3. Install the required libraries if needed.
4. Run the notebook cells in order.
